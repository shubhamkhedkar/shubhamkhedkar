## 👋 About Me

I'm a **Software Developer** moving deeper into **DevOps and Cloud engineering**. I enjoy building working software and then automating how it gets tested, secured, packaged and shipped.

I'm currently learning **multi-cloud DevOps** in the *CloudDevOpsHub* **Multi Cloud + DevOps with AI Challenge (Batch-45)**, and I turn what I learn into hands-on projects: CI/CD pipelines, AWS tooling, Kubernetes demos and AI-assisted security automation.

- 🔭 Building: CI/CD pipelines, AWS cost & security tooling, Kubernetes self-healing demos
